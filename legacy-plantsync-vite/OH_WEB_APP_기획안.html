01 · 서비스 개요

왜 이 시스템이 필요한가

본 시스템은 발전소 정기 오버홀 기간 중 기계·전기·제어 분야의 공정 현황을 효율적으로 관리하기 위한 웹 기반 공정관리 시스템이다. 관리자가 오버홀 설계내역서 엑셀 파일을 업로드하면 시스템은 설비명, 구성품, 규격, 수량, 단위 정보를 자동으로 추출하여 공정관리용 작업항목으로 변환한다. 이후 분야별 담당자가 하루 1회 실제 완료 물량을 입력하면 시스템은 물량 기준 공정률, 설비별 진행률, 분야별 진행률, 계획 대비 실적, 입력 누락 현황, 지연 위험 공정을 자동 산정하고 대시보드와 보고서로 시각화한다.

가장 중요한 목적 — 직원이 엑셀 내역서를 별도로 가공하지 않아도, 업로드만으로 오버홀 공정관리 화면이 자동 생성되도록 하는 것.
02 · 문제와 목표

업무상 문제점 → 시스템 도입 목표

설계내역서·공정표·실적관리표·보고자료가 분리되어 있어 발생하는 문제를 목표로 1:1 대응해 해소한다.

⚠ 업무상 문제점

  1. 1설계내역서 엑셀을 공정관리용 자료로 다시 정리해야 한다.
  2. 2설비별, 분야별 작업 현황을 한눈에 보기 어렵다.
  3. 3일일 실적 입력 누락 여부를 수작업으로 확인해야 한다.
  4. 4실제 물량 기준 공정률 산정이 번거롭다.
  5. 5경영진 보고자료와 일일보고서를 매번 별도로 작성해야 한다.
  6. 6분해 전/후 사진이 작업항목과 연결되지 않아 관리가 어렵다.

🎯 시스템 도입 목표

  1. 1설계내역서 업로드만으로 작업항목 자동 생성
  2. 2설비별·분야별 공정 현황 자동 시각화
  3. 3실제 완료 물량 입력 기반 공정률 자동 계산
  4. 4입력 누락 및 지연 위험 공정 자동 알림
  5. 5일일보고서, 경영진 보고서, 엑셀 다운로드 자동 생성
  6. 6분해 전/후 사진을 작업항목별로 체계적으로 관리
  7. 7PC와 모바일 모두에서 사용 가능한 외부 접속형 웹앱 구축
03 · 적용 범위

대상 업무 · 분야 · 기간

발전소 연간 정기 오버홀 공정관리 업무 전반을 대상으로 하며, 기계·전기·제어 3개 분야를 포괄한다.

04 · 사용자 권한

관리자 · 담당자 · 조회자 — 3단계 권한 체계

LEVEL 01

관리자

주요 권한

  • 오버홀 프로젝트 생성 / 설계내역서 업로드
  • 엑셀 자동분석 결과 확인 / 공정표 자동 생성
  • 작업항목 확정 및 담당자 지정
  • 실적 입력·수정, 사진 등록·삭제
  • 일일·경영진 보고서 생성, 엑셀 다운로드
  • 입력 누락·지연 공정 확인, 사용자 권한 관리
LEVEL 02

담당자

주요 권한

  • 본인 담당 분야 작업 조회
  • 일일 실제 완료 물량 입력
  • 금일 작업내용 / 지연사유 / 조치계획 입력
  • 분해 전·후 사진 업로드
  • 본인 입력 내역 조회

제한 사항

  • 엑셀 설계내역서 업로드 불가
  • 프로젝트 삭제, 타 분야 실적 수정 불가
  • 사용자 권한 변경 불가
LEVEL 03

조회자

주요 권한

  • 대시보드 / 설비별·분야별 공정률 조회
  • 지연 공정 조회
  • 보고서 조회, 엑셀 다운로드

제한 사항

  • 실적 입력, 사진 업로드 불가
  • 프로젝트 설정 변경 불가
  • 작업항목 수정 불가

07 · 공정률 산정 기준

물량 기준 자동 공정률 계산

각 작업항목은 계획수량과 실제 완료수량을 가지며, 담당자가 실제 완료수량을 입력하면 시스템이 작업별 공정률을 자동으로 계산한다.

// 작업별 공정률 산정 공식
작업별 공정률 = 실제 완료수량 ÷ 계획수량 × 100
참고 — 원본 PRD 문서는 "7.2 작업별 공정률" 공식까지 작성된 상태이며, 설비별·분야별 진행률 및 계획 대비 실적 세부 산정식은 원본 문서 보완 후 이 기획안에 추가 반영이 필요하다.
